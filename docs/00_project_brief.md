# 00 Project Brief

## Summary

Fragment Autocomplete is a research software project focused on candidate reconstruction of medieval manuscript fragments. Early work should prioritize structured layout understanding, provenance, and uncertainty-aware outputs.

## Core position

- layout-first reconstruction
- eManuSkript-centered layout analysis backbone
- CoMMA as text and metadata support, not the primary visual dataset
- scholarly hypotheses, not deterministic reconstruction claims

## Immediate scope

This document set currently supports planning and repository organization only.
